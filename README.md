v1.0 -   This is a basic script to create drawings for E-core based planars in FreeCAD using the python console.
         You can adjust the parameters in the configuration section to suit your specific application.
         After params have been adjusted, copy and paste the script into the python console, and hit enter.
         As written, it will not run as a macro. This is something that could be included in future updates.
         
         The expectation is that this script will handle 95% of the work for you but that you may need
         to make some tweaks once you're in your ECAD software to improve coupling, adjust where exactly
         windings should start and end for your application, etc.
